## 📖 Tentang Program

Program **Upskilling** dirancang untuk membekali staff dengan keterampilan data science secara bertahap dan terstruktur — mulai dari memahami data mentah, membangun model prediktif, hingga mendalami konsep deep learning modern.

---

## 📚 Modul Pembelajaran

### 📊 Modul 1 — Exploratory Data Analysis
> _Memahami data sebelum memodelkannya_

Modul ini membahas teknik-teknik dasar dalam mengeksplorasi dataset: membaca distribusi, menemukan pola tersembunyi, menangani missing values, serta memvisualisasikan data secara efektif menggunakan Python.

**Topik utama:**
- Statistik deskriptif & distribusi data
- Visualisasi dengan Matplotlib & Seaborn
- Handling missing values & outliers

### 🤖 Modul 2 — Machine Learning Modelling
> _Membangun model dari data_

Modul ini mencakup alur kerja machine learning end-to-end: preprocessing data, memilih algoritma yang tepat, melatih model, dan mengevaluasi performa menggunakan metrik standar industri.

**Topik utama:**
- Supervised & unsupervised learning
- Feature engineering & selection
- Model evaluation (accuracy, F1, AUC-ROC)
- Cross-validation & hyperparameter tuning

### 🧠 Modul 3 — Deep Learning Fundamental
> _Mengenal neural network dari dasar_

Modul ini memperkenalkan konsep dasar deep learning: arsitektur neural network, fungsi aktivasi, proses training, serta penerapan framework modern seperti TensorFlow atau PyTorch pada kasus nyata.

**Topik utama:**
- Arsitektur neural network & backpropagation
- Convolutional Neural Network (CNN)
- Recurrent Neural Network (RNN)
